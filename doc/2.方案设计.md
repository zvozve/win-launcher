# WinLauncher 方案设计

> 需求来源：`doc/1.开发需求,md`
> 目标：Windows 上做一个仿 macOS 启动台（Launchpad）的应用启动器
> 技术栈：**Qt 6.8.3 + MSVC2022 64bit**（本机已验证：`C:\Container\System\Library\QT\6.8.3\msvc2022_64`，Quick/Qml/QuickControls2/Svg/Widgets 模块齐全）

---

## 0. 一句话目标

全屏、毛玻璃、网格化的启动台；自动扫描系统已安装软件；支持拖入 `.lnk` 添加；独立的编辑界面增删图标。

---

## 1. 需求拆解

| 编号 | 需求 | 关键点 | 优先级 |
|---|---|---|---|
| F1 | 仿 macOS 启动台 | 全屏无边框、毛玻璃、网格、分页、搜索、拖拽排序 | P0 |

## 2. 架构选型（决策）

### 2.1 UI 层

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. 纯 QtWidgets | 控件成熟、`QFileIconProvider` 直接可用、上手快 | 动画/拖拽/毛玻璃吃力，做不出 macOS 质感 | 否 |
| B. 纯 QML | 动画流畅、模糊/拖拽/粒子现成 | Win32/COM 交互必须桥接 | 不完整 |
| **C. QML 界面 + C++ 后端** | 视觉表现力 + Win32/COM 能力兼得 | 需写 QObject 桥接层 | ✅ **推荐** |

理由：启动台的核心体验是「全屏毛玻璃 + 圆角网格 + 缩放动画 + 自由拖拽」，这些都是 QML 的舒适区；而扫描注册表、解析 lnk、激活 UWP 是 Win32/COM 的活，放 C++ 层最干净。两者用 `QAbstractListModel` + `Q_INVOKABLE` 桥接即可。

### 2.2 软件扫描范围

| 方案 | 覆盖度 | 复杂度 | 结论 |
|---|---|---|---|
| 只扫开始菜单 | ~70%（漏 UWP、漏免安装） | 低 | 兜底 |
| **开始菜单 + 注册表 + AppsFolder** | ~100% | 中 | ✅ **推荐** |
| 全盘 exe 索引（Everything 式） | 100%+ | 高、慢、噪音大 | 否 |

### 2.3 图标获取

| 手段 | 分辨率 | 适用 |
|---|---|---|
| `QFileIconProvider` | 常为 32/48，会糊 | 快速兜底 |
| `SHGetFileInfo` | ≤256（`SHIL_JUMBO`） | `.lnk`/`.exe` |
| **`IShellItemImageFactory::GetImage`** | 256 Jumbo，返回 HBITMAP→QImage | ✅ 通用，含 UWP |

图标统一缓存为 `cache/icons/<hash>.png`（256×256），避免每次启动重新提取。

### 2.4 毛玻璃背景

| 手段 | 系统 | 说明 |
|---|---|---|
| `SetWindowCompositionAttribute` + `ACCENT_ENABLE_ACRYLICBLURBEHIND` | Win10 1803+ | 兼容性最好，✅ 主选 |
| `DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE)` | Win11 22H2+ | 效果最正，做渐进增强 |
| QML 截图模糊（`MultiEffect`） | 任意 | 兜底，性能差 |

QML 侧需 `window.color = "transparent"` + `Qt::FramelessWindowHint`，否则 Win32 模糊被不透明背景盖住。

## 3. 模块划分（单入口）

```
WinLauncher/
├── app/main.cpp                 QGuiApplication + 窗口装配 + 单实例
├── core/                        ← C++ 后端，不依赖 QML
│   ├── AppScanner               扫描 开始菜单 / 注册表 / AppsFolder → AppItem[]
│   ├── IconExtractor            IShellItemImageFactory → 缓存 PNG
│   ├── ShortcutResolver         解析 .lnk 目标、读出 UWP AUMID
│   ├── Launcher                 启动：ShellExecuteEx / IApplicationActivationManager
│   ├── LayoutStore              layout.json 读写、图标缓存目录管理
│   └── GlobalHotkey             RegisterHotKey + 原生事件过滤
├── model/
│   ├── AppListModel             QAbstractListModel，暴露给 QML
│   └── EditModel                编辑态草稿（改完点「保存」再提交，可放弃）
├── ui/
│   ├── LauncherWindow.qml       全屏启动台：网格 / 分页 / 搜索
│   ├── EditWindow.qml           独立编辑窗：拖入 lnk、增删、排序
│   ├── components/AppIcon.qml / FolderTile.qml / SearchBar.qml / PageIndicator.qml
│   └── win/Acrylic.qml          Win32 模糊封装
└── resources/                   图标、字体、qrc
```

数据流单向：`AppScanner → AppListModel → QML`；编辑动作经 `EditModel → LayoutStore → 回写 AppListModel`。

## 4. 关键技术点

| 主题 | 做法 |
|---|---|
| 全屏窗口 | `Qt::FramelessWindowHint`；Esc / 失焦隐藏；`showFullScreen()` |
| 拖入 `.lnk` | `dragEnterEvent`/`dropEvent` 取 `mimeData()->urls()`；`.lnk` 走 IShellLink 解析，`.url`/`.exe` 直接收，其他类型忽略 |
| UWP 枚举 | 通过 `FOLDERID_AppsFolder` 的 `IShellFolder::EnumObjects`（SHCONTF）拿 AUMID |
| UWP 启动 | `IApplicationActivationManager::ActivateApplication(aumid)` |
| 普通启动 | `ShellExecuteEx(SEE_MASK_NOASYNC)`，带工作目录与参数 |
| 全局唤起 | `RegisterHotKey(hwnd, id, MOD_CONTROL\|MOD_ALT, 'L')`，用 `QAbstractNativeEventFilter` 收 `WM_HOTKEY` |
| 单实例 | `QLocalServer` 命名管道，二次启动唤起已有窗口 |
| 开机自启 | 注册表 `HKCU\...\Run` 写自身路径（不引第三方） |
| 图标失效 | 缓存 key = target 路径 + 文件 mtime + size，变更自动重提 |

### 数据格式 `%APPDATA%\WinLauncher\layout.json`

```json
{
  "version": 1,
  "grid": { "cols": 7, "rows": 4 },
  "pages": [
    [
      { "id": "guid", "name": "Chrome", "icon": "icons/ab12.png",
        "kind": "lnk", "target": "C:\\...\\chrome.exe", "args": "", "aumid": "" },
      { "id": "guid", "name": "计算器", "icon": "icons/cd34.png",
        "kind": "uwp", "target": "", "args": "", "aumid": "Microsoft.WindowsCalculator_8wekyb3d8bbwe!App" }
    ]
  ]
}
```

## 5. 里程碑（先核心后扩展，每阶段可独立验收）

| 阶段 | 交付 | 验收标准 |
|---|---|---|
| **M1 骨架** | CMake 工程（Ninja + MSVC2022）+ 全屏无边框窗 + 毛玻璃 | 能全屏唤起/退出，透过窗口看到模糊桌面 |
| **M2 扫描** | AppScanner + IconExtractor，结果打印/列表显示 | 开始菜单软件全部列出；图标 256px 不糊 |
| **M3 启动台 UI** | 网格 / 分页 / 搜索 / 点击启动 | 点图标能拉起对应程序（含 UWP） |
| **M4 编辑** | 独立编辑窗，拖入 `.lnk`、增删、排序 | 拖入 `.lnk` 立即新增；删除即时生效 |
| **M5 持久化** | `layout.json` + 图标缓存 | 重启后布局与图标完全保持 |
| **M6 唤起** | 全局热键 + 托盘 + 单实例 + 开机自启 | 任意界面热键唤起 |
| M7（可选） | 文件夹分组、多页滚动动画、拖拽归档 | 分组与拖动整理流畅 |
